# ReMobile - AI Based E-Waste Recovery System

ReMobile is an AI-based system to reduce e-waste. It identifies old mobile phones and suggests whether they can be repaired, recycled, or reused.

## Features
- Identify mobile model and condition using AI
- Suggest Repair / Recycle / Reuse
- Helps in reducing e-waste pollution

## Tech Stack
- Python, HTML, CSS, JavaScript, React, MySQL
